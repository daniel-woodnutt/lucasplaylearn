# Project guidance

## 3D scene quality

- Join parts that are meant to form one object. Avoid visible gaps between house walls and roofs, or between an animal's or person's head, body, ears, arms, and legs.
- Keep feet, furniture, props, and structures in contact with the ground unless floating is intentional. Check placement using the mesh's actual dimensions, not just its node origin.
- Inspect composite objects from the gameplay camera and other relevant angles. Check that joins remain convincing during animations as well as in the idle pose.

## Consistent visual style

- Keep all scenes within the same established visual style: use a shared palette, shape language, material finish, lighting, camera perspective, scale, and UI treatment.
- Reuse shared materials, themes, and scene components where practical instead of introducing one-off styles in each scene.
- When adding a scene or asset, compare it with existing scenes in the game and adjust it to match. Make intentional departures explicit.
- Before finishing visual work, run the game and inspect the result in context; verify object joins, ground contact, and consistency from the player's view.
